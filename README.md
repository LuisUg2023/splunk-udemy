# Portafolio — Introducción a Splunk (Udemy)

Repositorio dedicado exclusivamente al curso **Introducción a Splunk de Udemy**.

## Contenido
Las notas y 11 lecciones del curso están organizadas en [curso/](./curso/README.md). Incluyen conceptos de arquitectura, canalización de datos, componentes, campos, archivos de configuración y preguntas de repaso.

## Alcance
Este repositorio documenta el contenido formativo de Udemy. No incluye los cursos ni las evaluaciones de la plataforma oficial Splunk Training, que se organizan por separado en [splunk-training](https://github.com/LuisUg2023/splunk-training).

## Evidencias
Los ejemplos de SPL y configuración son material de estudio. No representan resultados de ejecución salvo que se adjunten capturas y observaciones verificables.
